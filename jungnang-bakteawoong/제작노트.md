## 콘셉트

고른 콘셉트는 A안 '눈을 뜨다 — 질문하는 사람'이다. 대표작 제목으로 눈을 뜨며 시작하고, 행사 이름 '책문(策問)'의 붉은 인장으로 닫는다. 책문은 임금이 묻고 선비가 답하던 시험 문제다.

버린 후보는 두 가지다(자세한 비교는 `concept.md`).
- B안 데이터 대시보드: 템플릿처럼 보이고 웅장한 느낌과 맞지 않았다.
- C안 중랑 지도: 행사 장소를 확인하지 못했다.

## Claude가 정한 것

- 무드는 웅장하게 잡았다. 팔레트는 먹·한지·인주다.
- 음악은 D단조 90BPM 합성 오케스트라다. ElevenLabs 키가 없어 `synth_music.py`로 만들었다.
- 길이는 30초, 화면은 16:9다.
- 화면 시각은 음악 마디에 고정했다. 나레이션을 나중에 넣어도 다시 렌더할 필요가 없다.

## 요청과 다르게 반영한 것: 나레이션이 아직 들어가지 않았다

나레이션을 넣지 못한 이유는 세 가지다.
- 이 환경에 ElevenLabs API 키가 없다.
- Microsoft 음성 서버(speech.platform.bing.com)는 네트워크 정책에 막혀 있다.
- 쓸 수 있는 오프라인 한국어 TTS(sherpa-onnx VITS KSS)로 만들어 오프라인 STT로 받아쓴 결과, 이름과 행사명을 잘못 읽었다. '박태웅'은 '다태우', '파티뭐'로, '중랑책문'은 '중단챙문'으로 받아써졌다. 작가 이름을 잘못 읽는 음성은 공개용으로 쓸 수 없어 넣지 않았다.

원고와 시각은 `narration_plan.json`에 정해 두었다. 음성을 넣는 방법은 두 가지다.

1. ElevenLabs 키가 있을 때: `narration_plan.json`의 lines를 `script.json`으로 옮긴다. 그다음 아래 명령을 차례로 실행한다. 영상은 다시 렌더하지 않는다.
   ```
   narrate.py script.json --stt
   timeline.py script.json --music-analysis audio/music/analysis.json
   mix.py timeline.json
   finish.py ...
   ```
2. 직접 녹음할 때: 줄마다 `audio/vo/n01.wav` 같은 파일로 녹음한다. 위 표의 시각에 맞춰 읽으면 된다.

## 공개 전 확인할 것

- 행사 정보: 웹 검색으로 '중랑책문'을 찾지 못했다. 일시(10.15 목)는 요청 문구를 따랐고, 요일은 달력으로 확인했다. 장소, 시간, 신청 방법은 넣지 않았다. 주최 측 정보로 엔드카드에 더할 수 있다.
- 직함과 연도: 조사 출처는 `research/research.md`에 있다. 모두 검색 결과 요약에서 가져왔고 원문 페이지는 열지 못했다.
  - '한빛미디어 이사회 의장'은 전직이라 '前'으로 표기했다.
  - 국가인공지능전략위원회 직함은 시점이 지나면 바뀔 수 있다.
- 책등 디자인: 실제 표지를 흉내 내지 않은 타이포그래피 표현이다.
- 사운드: Claude는 소리를 들을 수 없고 수치로만 확인했다. 음악과 효과음을 직접 들어 봐 주세요.
