## 한글 타이포그래피

| 용도 | 크기(1080p 기준) | 규칙 |
| --- | --- | --- |
| 디스플레이 헤드라인 | 120~260px | 900 굵기, 자간 -0.03~-0.05em, 행간 1.05, 두 줄 이하 |
| 1~3자 단어·이름 | 300~480px | 화면을 가득 채워도 된다 |
| 거대 숫자 | 200~400px | Anton 또는 Pretendard 900, `tabular-nums`, 단위는 본문 서체로 작게 |
| 본문·설명 | 40~64px | 화면 한 장에 20자 안팎 |
| 자막 | 38~44px | 하단 64~104px, 그림자 2겹 |
| 라벨·HUD | 15~22px | Mono 대문자, 자간 0.14~0.5em |
| 최소 크기 | 읽어야 하는 글자 32px, 부제·CTA 48px | 엔드카드 CTA 를 가장 작은 글자로 두지 않는다 |

- `word-break: keep-all`을 쓴다(템플릿에 들어 있다). 어절 중간에서 줄이 바뀌거나 조사만 다음 줄로 떨어지면 줄을 직접 나눈다(`<br>`).
- 영문 디스플레이 서체(Anton, JetBrains Mono)에는 한글이 없다. 폰트 스택 끝에 Pretendard를 둔다. 템플릿 변수(`--num`, `--mono`)에 이미 들어 있다.
- 글자를 음절 단위로 쪼개 움직여도 읽힌다(`REEL.split`). 마스크 리빌은 `split(el, 'char', {mask: true})`를 쓴다. 마스크 여백(.12em/.18em)이 있어야 받침·윗점이 잘리지 않는다.
- 마스크 안 글자에 `text-shadow`를 주면 사각형 잔상이 생긴다. 글로우는 같은 글자를 blur 한 복제 레이어로 따로 그린다.
- 그라디언트 글자(`background-clip: text`)는 transform이 걸린 자식 span 에서 사라진다. 글자마다 그라디언트를 걸고 `background-position`을 이어 붙인다.
- 강조는 문장 안 핵심어 하나에만 강조색을 칠한다.

## 레이아웃과 안전 영역

16:9 (1920×1080):

- 본문 안전 영역 x 120~1800, y 120~900
- HUD는 가장자리에서 46px 안쪽
- 자막 영역 y 940~1040. 자막이 있는 영상은 그래픽을 y 900 아래로 내리지 않는다
- 카메라가 움직이는 장면에서도 자막 영역은 비워 둔다. 완성 MP4에서만 겹침이 드러난 사례가 있다

9:16 (1080×1920):

- 위 250px(앱 상단 UI)와 아래 400px(캡션·버튼)를 비운다
- 헤드라인은 화면 폭의 80% 이내, 한 줄 6~8자
- 가로 사진은 가상 카메라로 확대해 피사체를 따라간다(scale 2 안팎)

## 모션 규칙

| 항목 | 값 |
| --- | --- |
| 등장 | `ease.snap`(0.16,1,0.3,1) 또는 outQuart, 0.35~0.7초, 이동 100~400px |
| 퇴장 | `ease.exit`(0.7,0,0.84,0) 또는 inCubic, 0.25~0.4초. 컷 0.1초 전에 끝낸다 |
| 여러 요소 | 0.03~0.08초 간격 스태거 |
| 칩·아이콘 | `ease.pop` 또는 스프링(진동수 2.2, 감쇠 0.42) |
| 슬램 | scale 1.9~2.8 → 1, blur 14~24 → 0, 0.25~0.32초, 히트 프레임에 착지 |
| 흔들림 | 진폭 12~18px, 감쇠 0.4초. 큰 히트에만 |
| 섬광 | 어두운 배경 opacity 0.08~0.15, 0.12~0.25초. 1초에 3회 이하 |
| 정지 금지 | 1초 넘게 멈춘 화면이 없게 한다. 장면 전체에 scale 1→1.04 또는 드리프트 4~6px |
| 숫자 | 카운트업 1.2~1.8초 outQuart. 작은 값은 굴리지 말고 한 번에 찍는다(중간값이 실제 값처럼 읽힌다) |
| 큐 동기 | 핵심 문구는 나레이션 큐 ±3프레임 안에 등장. 큐보다 2프레임 먼저 시작해도 좋다 |
| 마지막 프레임 | 마지막 10프레임에 새 정보를 넣지 않는다 |

느리고 작은 움직임은 슬라이드처럼 보이므로, 이동은 크게 시간은 짧게 한다.

### 역동성 규칙

같은 요청을 스킬 없이 만든 영상과 비교했을 때 차이가 난 항목이다. 초안마다 `motion_check.py`로 확인한다.

| 항목 | 규칙 | 도구 |
| --- | --- | --- |
| 변화 주기 | 정보 구간에서는 0.5~1박마다 화면에 새 사건(등장·숫자·재배치)이 있다. 같은 구도를 2마디(약 4초) 넘게 두지 않는다. 장면 경계와 몽타주 컷은 마디에 놓고, 클라이맥스 앞에서는 1마디 → 반 마디 → 1박으로 컷을 줄인다 | `REEL.bar(n)`, 큐 `bar9` |
| 퇴장 | 투명도만 바꾸지 않는다. 위로 140px·0.9배·흐림으로 밀려 나가거나, 다음 장면으로 줌 스루하거나, 다음 구도의 자리로 날아간다 | `REEL.inout(el, t, a, b)` |
| 큰 타격 | 예고(모여드는 입자·라이저 0.5~2초) → 타격(빛점·충격파·사방 빛줄기·플레어 + 1.3배·흐림에서 착지하는 글자 + 흔들림 0.4초) → 여운(빛줄기·먼지). 1분에 3~6번 | `FX.impact`, `FX.camera({ shakes })`, `FX.rays` |
| 전환 | 짧은 영상일수록 화면 전체가 움직이는 전환을 쓴다: 휩 팬, 슬랫 와이프, 색 면 플래시. 10초에 한 번 이상(15~30초 영상) | `FX.camera({ whips })`, `FX.wipe` |
| 배경 | 검은 배경 위 글자만 있는 화면은 푸시를 넣어도 멈춘 것으로 보인다. 장면 뒤에 움직이는 면(흘러오는 격자 바닥, 켄 번스 사진, 먼지)을 깐다 | `FX.floor`, `FX.dust`, 장면 `push` |
| 소리 반응 | 화면 어딘가가 늘 음악·목소리에 반응한다(파형 막대, 박마다 커지는 링, 박마다 밀려 들어오는 카메라) | `REEL.level`, `REEL.pulse`, `FX.camera({ beat })` |
| 말과 글자 | 화면 문장은 말하는 시각에 맞춰 글자 단위로 올라온다. 핵심어는 200px 이상 마스크 상승 | `REEL.charTimes`, `REEL.sayChars` |

기준(멈춘 화면 비율, 큰 움직임 p90): 20초 이하 8%·15, 60초 이하 20%·7, 그보다 긴 영상 35%·6.

## 전환 기법

같은 전환을 세 번 연속 쓰지 않는다. 전환이 전체 길이의 15%를 넘으면 줄인다.

| 전환 | 방법 | 어울리는 곳 |
| --- | --- | --- |
| 색면 와이프 | 강조색 면이 들어왔다가(origin 왼쪽) 반대로 빠짐(origin 오른쪽), 0.2+0.3초 | 챕터 전환 |
| 줌 스루 | 화면 속 한 점(눈동자, 글자 구멍, 화면)을 inExpo로 7~9배 확대 + 섬광 | 오프닝 → 본편 |
| 매치 컷 | 앞 장면의 도형(점·선·기호)이 다음 장면의 다른 요소로 이어짐 | 모티프 연결 |
| 마스크 리빌 | `clip-path: inset()`·`circle()`이 열림 | 사진·카드 등장 |
| 슬랫 | 세로 막대 7~9개가 차례로 열림. 다 열린 뒤 한 장의 이미지로 바꿔 이음선을 없앤다 | 사진 몽타주 |
| 푸시 | 다음 장면이 밀고 들어오며 앞 장면은 -35% 이동 | 목록·순서 |
| 글리치 컷 | 0.1초 가로 슬라이스 + RGB 분리 | 테크·반전 |
| 정지 + 암전 | 음악 stop과 함께 0.5~1초 검은 화면, 글자 한 줄 | 전환점·반전 |
| 풀 백 | 카메라가 뒤로 빠지며 전체 구조가 드러남 | 단계·시스템 설명의 마무리 |

## 쇼릴 장치(HUD·필름 요소)

`fx.js`에 들어 있다. 사용법은 `engine.md`.

- 모서리 브래킷 + 타임코드 + 챕터 라벨(`CH.01 / PROOF`) + 하단 진행 바: 촬영본 같은 인상을 준다. 오프닝 3초와 엔드카드에서는 숨긴다.
- 레터박스: 오프닝에서 닫혀 있다가 첫 큰 히트에 열린다.
- 필름 그레인·비네트: 모든 장면에 얇게.
- 라이트 리크: 장면이 바뀌는 순간 한두 번.
- 반복 모티프: 영상 전체를 잇는 도형 하나(점, 세로 막대, 선)를 정해 장면마다 다른 역할로 쓴다. 첫 장면의 점이 마지막 로고의 점이 되는 식이다.

## 하지 않을 것

- 제목 + 불릿 목록 화면(슬라이드처럼 보인다), 한 화면에 세 줄 넘는 문장
- 의미 없는 파티클·렌즈 플레어·과한 글리치
- 숫자 없는 형용사 카피("혁신적인", "획기적인")
- 다른 회사 로고를 그리거나 실존 인물 얼굴을 합성하는 것
- 이모지(톤이 깨진다. 아이콘은 SVG로 그린다)
- 화면 전체에 blur 필터를 여러 겹 거는 것(렌더가 몇 배 느려진다)
