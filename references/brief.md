# 기획 브리프

브리프는 사용자 확인을 받는 유일한 단계다. 여기서 정하지 않은 것은 뒤에서 기본값으로 처리되므로, 결과물에 큰 영향을 주는 항목만 묻고 나머지는 기본값을 보여 준다.

## 목차

- 질문하기 전에
- 질문 세트
- 브리프 양식
- 시간·크레딧 추정
- 조사 요청 프롬프트
- 사진 수집 요청 프롬프트

## 질문하기 전에

1. 사용자 요청에서 이미 정해진 항목을 표시한다. 예를 들어 "웅장한 1분 나레이션 영상"이면 분위기·길이·나레이션은 묻지 않는다.
2. `preflight.py` 결과로 불가능한 선택지를 뺀다. 키가 없으면 나레이션 선택지에 "키 발급 후 진행"을 붙이고, codex가 없으면 이미지 생성 선택지에 "스킬 설치 필요"를 붙인다.
3. 주제 자체(누구·무엇)가 요청에 없으면 선택지 질문을 하기 전에 한 줄로 묻는다. 주제는 선택지로 고를 수 없다.
4. 요청에 날짜와 요일이 함께 있으면 달력으로 대조한다. 맞지 않으면 브리프 요약에 적어 확인을 받는다(브리프 확인 없이 진행하는 경우에는 요일을 빼고 보고에 적는다).

## 질문 세트

AskUserQuestion은 한 번에 질문 네 개, 질문마다 선택지 2~4개를 받는다("기타"는 자동으로 붙는다). 추천 선택지를 맨 앞에 두고 라벨 끝에 "(Recommended)"를 붙인다.

### 1차 (핵심 네 가지)

**분위기·테마**(header: 분위기)
- 웅장한 시네마틱 (Recommended): 어두운 화면, 금색 강조, 레터박스, 오케스트라·타이코
- 테크 키노트: HUD·그리드·데이터 시각화, 일렉트로닉 펄스
- 미니멀 프리미엄: 여백 많은 에디토리얼, 세리프, 피아노·현악
- 경쾌·팝: 밝은 색, 스프링 팝 모션, 스티커, 업비트

목록에 없는 무드(감성 다큐, 레트로 글리치 등)는 "기타"로 받는다. 무드별 상세는 `design.md`.

**길이**(header: 길이)
- 60초 (Recommended)
- 15초: 한 메시지·SNS 티저
- 100초: 서사가 있는 브랜드 필름
- 5분: 교육·설명(챕터 구성)

30초는 "기타"로 받는다. 여러 길이를 원하면 긴 버전을 먼저 만들고 짧은 버전은 같은 장면을 다시 편집한다.

**나레이션**(header: 나레이션)
- Marcus 깊은 바리톤 (Recommended): 웅장한 한국어 남성 보이스
- 다른 보이스 추천: 후보 2~3개를 같은 문장으로 들려 주는 대신 STT·음역 수치로 골라 보고에 적는다
- 나레이션 없음: 음악과 화면 타이포로만 전달

**이미지**(header: 이미지)
- AI 생성 + 실제 자료 (Recommended): 실제 사진·로고에 분위기 컷을 생성해 보탠다
- AI 생성 이미지 위주
- 실제 사진·자료만: 사용자 제공 또는 공개 자료
- 이미지 없이 타이포·그래픽

### 2차 (필요할 때만)

1차 답과 요청으로 정해지지 않은 항목만 묻는다.

- **화면비**: 16:9 가로 (Recommended) / 9:16 세로(릴스·쇼츠) / 1:1
- **꼭 넣을 정보**: 이름·직함·날짜·장소·URL·CTA 문구. 선택지로 "조사해서 채움 (Recommended)" / "아래에 직접 적음"을 주고 "기타"로 받는다.
- **자료 위치**: 사진 폴더·로고·참고 URL이 있는지. "현재 폴더의 파일 사용" / "웹에서 조사·수집" / "없음"
- **음악**: ElevenLabs Music으로 작곡 (Recommended, 유료 플랜) / 무료 합성 음악 / 가지고 있는 음원 파일

## 브리프 양식

답을 받으면 `<프로젝트>/brief.md`를 쓰고, 아래 요약을 사용자에게 보여 준 뒤 진행 여부를 한 번 묻는다.

```markdown
# 브리프 — <제목>

- 주제·목적: <누구·무엇을> <누구에게> 보여 주는 <용도> 영상
- 길이·규격: 60초 · 16:9 1920×1080 · 30fps
- 분위기: 웅장한 시네마틱 (팔레트: 잉크 #05060a / 웜 화이트 #f3efe6 / 금색 #f5b942)
- 구성안: 콜드 오픈 훅 → 이름 공개(9초) → 경력 4장 → 수렴 문장 → 이름 카드 (story.md 의 "인물 프로필")
- 나레이션: Marcus · 약 250자 · 화면 자막 번인
- 이미지: 실제 사진 N장(출처: …) + 생성 컷 N장(얼굴 없는 환경 컷)
- 음악: ElevenLabs Music, 90 BPM D 단조 시네마틱 (불가 시 합성)
- 꼭 넣을 정보: …
- 산출물: <제목>_60s.mp4, _공유용.mp4, _포스터.jpg, .srt, 제작노트.md
- 프로젝트 폴더: <절대 경로>
- 예상: 작업 약 60~90분 · ElevenLabs 약 N 크레딧 · 이미지 N장
```

사용자가 확인하면 이후에는 질문하지 않는다. 진행 중 바뀐 결정은 납품 보고에 적는다.

## 시간·크레딧 추정

과거 제작 기록에서 나온 값이다. 브리프의 "예상" 줄에 쓴다.

| 길이 | 작업 시간 | 나레이션 글자 | 장면 수 | 구도 수 | 최종 렌더(모션 블러 4) |
| --- | --- | --- | --- | --- | --- |
| 15초 | 30~50분 | 50~65자 | 4~6개 | 10~14개 | 약 1분 |
| 30초 | 30~60분 | 100~130자 | 6~10개 | 15~22개 | 약 2분 |
| 60초 | 50~90분 | 220~255자 | 7~12개 | 25~35개 | 3~5분 |
| 100초 | 70~120분 | 360~420자 | 15~25개 | 40~50개 | 6~9분 |
| 120초 | 60~120분 | 300~380자 | 15~25개 | 45~60개 | 10~13분(워커 2) |
| 5분 | 2~3시간 | 1,150~1,300자 | 약 25개 | 90~120개 | 15~25분 |

ElevenLabs 크레딧(대략):

- TTS: 글자 수 × 1(재생성·takes 포함 약 1.5~2배)
- STT: 분당 소량
- 효과음: 길이를 지정하면 초당 40 크레딧(효과음 10종 × 2초 ≈ 800)
- 음악: 길이에 비례

User Read 권한이 없는 키는 잔여 크레딧을 조회할 수 없으므로 대시보드에서 확인하라고 안내한다.

이미지 생성: codex-image 장당 약 1분, 5장 병렬. ChatGPT 플랜 사용량이 장수만큼 차감된다.

## 조사 요청 프롬프트

인물·기업·행사·제품이 주제면 서브에이전트(`general-purpose`)를 백그라운드로 띄운다. 그동안 메인은 프로젝트 준비·폰트·보이스 확인·배경 이미지 생성을 진행한다.

```
<대상>에 대해 조사해 <프로젝트>/research/research.md 에 써라. 기억에 의존하지 말고 WebSearch·WebFetch 로 확인한 사실만 쓴다.
(WebFetch 가 막힌 사이트는 curl -sL -A "Mozilla/5.0" 로 받아 본문을 뽑는다.)
1. 연표: 연도 · 직함/사건 · 출처 URL · 확실도(확인 / 단일 출처 / 미확인)
2. 영상에 쓸 만한 사실 TOP 10: 숫자·직함·수상·성과 위주. 숫자는 기준 시점을 함께
3. 본인·공식 인용문(원문 그대로, 출처)
4. 서로 다른 정보(출처끼리 다른 수치·연도)와 동명이인 주의
5. 영상 자막용 짧은 카피 후보 15개(각 20자 이내, 사실에 근거한 것만)
6. 브랜드 색(공식 사이트 CSS 의 hex 빈도), 공식 로고 파일 URL
7. "대본에 넣지 말 것": 확인 안 된 학력·생년·수치
마지막에 파일 경로와 TOP 10 만 짧게 보고하라.
```

## 사진 수집 요청 프롬프트

실제 인물 사진이 필요하고 사용자가 사진을 주지 않았을 때 쓴다. 인물 얼굴을 AI로 만들지 않기 위한 단계다.

```
<인물>의 실제 사진을 모아 <프로젝트>/assets/photos/ 에 저장하고 <프로젝트>/research/photos.md 에 표로 정리하라.
- 우선순위: 공식 프로필·회사 보도자료 > 언론 기사 사진(og:image) > 본인 공개 SNS
- 네이버 뉴스 검색 결과 HTML 을 curl 로 받아 기사 URL 을 뽑고, 기사 HTML 의 og:image 를 받는다(브라우저 UA·Referer 지정)
- 받은 사진은 Read 로 직접 열어 본인인지(캡션에 이름과 직함이 함께 있는지), 워터마크, 해상도를 확인한다. 동명이인은 버린다
- 표: 파일명 · 원본 URL · 기사 URL · 해상도 · 내용(정면/무대/행사) · 품질
- 8~15장, 긴 변 800px 이상 우선
```
