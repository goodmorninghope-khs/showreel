# 류경기 중랑구청장 등장 영상 v2 (24초, 범용) — 록 공연 등장

사용자 피드백: 소리가 안 들림 / 공연장에서 로커가 등장하듯 관중과 구청장을 교차시켜 더 극적으로.

- 소리: v1 합성 음악은 에너지의 54%가 100Hz 아래(팀파니·붐)여서 휴대폰·노트북 스피커에서 거의 들리지 않았다.
  v2는 `tools/rock_music.py`로 중음역 중심 록 트랙을 직접 합성했다. 기타 파워코드, 스네어, 관중 박수, 함성이 들어가며,
  100Hz 아래 비중은 10%(효과음 포함 믹스 18%)다.
- 관중은 실존 인물이 아닌 역광 실루엣이다(코드로 그림: 들어 올린 팔, 휴대폰 불빛, 장미색 응원봉).
  구청장은 사용자 제공 사진의 클로즈업 4컷과 누끼 전신을 쓴다.

| 시각 | 음악 | 화면 |
| --- | --- | --- |
| 0–4 | 관중 웅성임, 심장박동 킥, 기타 피드백 | 암전된 공연장, 조명, 관중. '모두가 기다린 그 순간' |
| 4–11.45 | 박수, 4비트 킥, 팜뮤트, 스네어 롤 가속 | 박자마다 관중 ↔ 구청장(얼굴·마이크·배지·무대) 교차, 끝으로 갈수록 빨라짐. '중랑이 / 기다린 / 나의 자랑 / 우리 중랑' |
| 11.45–12 | 완전 정적 | 암전 |
| 12 | 크래시, 파워코드, 함성 폭발 | 불꽃, 스포트라이트, 인물이 솟고 '류경기' 슬램 |
| 12–20 | 풀 밴드 | 박마다 조명이 뛰고, 앞줄 관중이 응원봉을 흔든다 |
| 20–24 | 마지막 코드, 불꽃 | 정지 카드(서울특별시 중랑구청장 류경기 / 나의 자랑 우리 중랑) |
